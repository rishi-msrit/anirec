HOW TO RUN ANIME RECOMMENDER

The dependencies and environments were deleted to save space. To run the project, follow these steps:

Frontend:
1. Open PowerShell and navigate to the frontend folder:
   cd frontend

2. Restore dependencies:
   npm install

3. Run the development server:
   npm run dev

Backend:
1. Open PowerShell and navigate to the backend folder:
   cd backend

2. Recreate the Python virtual environment:
   python -m venv venv

3. Activate the virtual environment:
   .\venv\Scripts\Activate.ps1

4. Install the required Python packages:
   pip install -r requirements.txt

5. Run the backend server:
   uvicorn app.main:app --reload
